## 🚀 To put one live for a client (free)

1. Go to **app.netlify.com/drop**
2. Drag the business's folder onto the page → instant live link
3. Rename the link (Site settings) → e.g. `top-notch-barber-si.netlify.app`
4. Text that link to the owner with a script from `sales/02-outreach-scripts.md`
