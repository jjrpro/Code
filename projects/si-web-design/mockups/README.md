# Real Prospect Mockups — Staten Island (10312 area)

These are **draft sites for real, publicly-listed local businesses** that appear
to have **no website of their own** (only Yelp / Fresha / directory listings).
They're built to **show the owner** what a site could look like — the classic
"I already made you one" pitch (see `../sales/02-outreach-scripts.md`).

## ⚠️ Before you send / publish any of these

The info came from public listings (Yelp, Fresha, Google) and may be **out of
date or wrong**. Each file has a `⚠️ MOCKUP` comment at the top listing what to
confirm. **Verify with the owner before putting a site live.** Treat the copy,
hours, services, and prices as generic placeholders.

## How to use one as a pitch
1. Open the folder's `index.html` in a browser to preview it.
2. (Optional) Fix anything obvious; full verification can wait until the owner's
   interested.
3. Deploy free on Netlify and rename the link — see `../sales/04-deploy-guide.md`.
4. Send it with a script from `../sales/02-outreach-scripts.md`, or walk in and
   show it on your phone.
