# Add the artwork photos here

This site shows EyeCandy Art Studios' real paintings. Drop the 5 photos JR
provided into THIS folder with these exact names (so the page picks them up):

| Save the photo of… | as this filename |
|---|---|
| The red/coal **lion** mosaic ("By Gene Wagner") | `hero.jpg` |
| The stone **angel** with wings | `angel.jpg` |
| The golden butterfly-winged **fairy** | `fairy.jpg` |
| The crescent-**moon** fairy (over the fireplace) | `moon.jpg` |
| (optional) a photo of **Gene / the sailboat studio** | `about.jpg` |

Tips:
- JPG or PNG both work; just keep the filename exactly as above (lowercase).
- Portrait shots look best (the gallery tiles are tall).
- Until the files are added, the page shows elegant dark placeholders instead of
  the art — so it still previews cleanly, it's just missing the paintings.

When deploying to Netlify, drag the whole `eyecandy-art-studios` folder (with
this `img/` folder inside it) onto app.netlify.com/drop.
