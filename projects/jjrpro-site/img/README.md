# Add the JAURX brand banner here

Drop your gold **JAURX — Official Channel** banner into this folder named exactly:

    jaurx-banner.png   (or .jpg — but keep the name jaurx-banner.png)

It will appear at the top of the hero automatically. Until the file exists, the
site shows a styled gold "JAURX / OFFICIAL CHANNEL" wordmark as a stand-in, so
the page still looks complete.

When deploying to Netlify, drag the whole `jjrpro-site` folder (with this `img/`
folder inside it) onto app.netlify.com/drop.

Tip: a wide banner (roughly 1600–2000px wide) looks best in the hero.
