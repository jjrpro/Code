# Script format — Cinematic Curiosities

Every script follows this shape. 120–180 words total. Read time ~60–90s.

```
HOOK (≤2s, ≤14 words): a shock, a number, or a "you wouldn't expect" line.
BODY (90–140 words): the real content. One clear idea, 2–3 surprising facts,
     a turn or twist near the end. Researched, specific, not generic.
PAYOFF (1 line): the resonant takeaway — why this matters / lands emotionally.
CTA: "Follow for one new wonder a day."
```

Rules:
- Hook must work with sound OFF too (it'll also be the on-screen caption).
- Short sentences. Narration cadence, not essay cadence.
- One genuine insight per video — that's the authenticity bar.
- Vary the hook type across videos (number / question / contradiction / dare).
