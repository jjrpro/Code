## Common Whop gotchas

| Issue | Fix |
|---|---|
| "Channel not found" when connecting | The Whop bot isn't admin in JAURX yet — add it first |
| Hidden plan still shows on public page | Whop calls it different things — look for "Unlisted" or "Private link only" toggle |
| Can't set 25-spot quantity limit | Whop's free tier may not have this — track manually in a note, hide the plan after 25 sales |
| Test checkout fails with currency error | USD must be enabled in your Stripe account (Whop uses Stripe under the hood) |
| Subscription cancels don't kick from channel | Whop's bot needs Ban Users perm in JAURX — check admin settings |
